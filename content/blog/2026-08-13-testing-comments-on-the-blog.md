I've added a comment system! I know it's an odd thing to do, since this is a fairly inactive blog, but that's also what makes it a safe testing ground.

I've wanted a comment system ever since I switched to a static blog, but it's hard to find one that meets all my desiderata. It has to be hosted, but inexpensive--I don't want to figure out how to serve it myself, and I don't want to pay a lot of money when I basically expect zero comments. It has to be low friction and inclusive--I considered [Utterances](https://utteranc.es/), which requires logging into Github to comment. That's probably okay for this blog, but people who read *Dark Tales Sleuth* won't necessarily have a Github account. *And* it has to look like an active project. [Commentbox.io](https://commentbox.io/) looked almost perfect, but I don't see any activity around it since 2018. Also, I have reservations about using Google or Facebook authentication.

So I'm testing out [Remarkbox](https://www.remarkbox.com). It's pay-what-you-can and allows commenting without signing into anything. I know lack of verification is risky, but Remarkbox's email verification method was acting wonky. If it becomes a problem, I can turn off the comment auto-approval.

So feel free to try it, below. You don't need to log in to anything (unless you want to be notified about replies); just type in the comment box. Markdown will work.

If this works okay, I'll probably add comments to *Dark Tales Sleuth*, too.
