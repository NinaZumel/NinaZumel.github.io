I've added a comment system! I know it's an odd thing to do, since this is a fairly inactive blog, but that's also what makes it a safe testing ground.

I've wanted a comment system ever since I switched to a static blog, but it's hard to find one that meets all my desiderata. It has to be hosted, but inexpensive--I don't want to figure out how to serve it myself, and I don't want to pay a lot of money when I basically expect zero comments. 

It has to be low friction and inclusive. I considered [giscus](https://giscus.app/), which requires logging into Github to comment. That's probably okay for this blog, but people who read *Dark Tales Sleuth* won't necessarily have a Github account. *And* it has to look like an active project. [Commentbox.io](https://commentbox.io/) looked almost perfect, but I don't see any activity around it since 2018. Also, I have reservations about using Google or Facebook authentication.

[Remarkbox](https://www.remarkbox.com) seemed like an option. It's pay-what-you-can and allows commenting without signing into anything. But it proved to be too wonky to use, and it doesn't seem to be well supported, so I rejected it.

Now I'm trying [Komments](https://komments.cloud). It's not in active development either, but it seems stable. It's extremely simple and manual, but also 
[not magic](/blog/2024-02-21-clarity-not-magic/), which suits me just fine. Looks better than Remarkbox, too.

So feel free to try it, below. You don't need to log in to anything; just type in the comment box. Markdown will work. Leave your email address if you want to be notified of replies, or if you'd like me to reply to you by email.

Because it's manual, I probably won't be adding comment sections to older posts (I did add one to "Digital Difficulties," just for testing purposes). But you can always get in touch with me by email, via the mail icon in the footer.
